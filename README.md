# Guia Financeiro IA

## Descrição

O Guia Financeiro IA é um projeto desenvolvido em Python com o objetivo de simular uma experiência de relacionamento financeiro utilizando conceitos de Inteligência Artificial, processamento de linguagem natural e simulações financeiras.

## Funcionalidades

- FAQ inteligente sobre conceitos financeiros
- Respostas contextualizadas para perguntas frequentes
- Histórico de conversa
- Simulador financeiro com juros compostos
- Interface executável no Google Colab

## Tecnologias Utilizadas

- Python
- Google Colab
- GitHub

## Exemplos de Perguntas

- O que é CDI?
- O que é Tesouro Direto?
- O que é cartão de crédito?
- Como funciona um empréstimo?
- O que são juros compostos?

## Simulador Financeiro

O sistema permite calcular:

- Valor investido
- Taxa de juros mensal
- Quantidade de meses
- Valor final do investimento
- Lucro obtido
